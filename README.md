# calendar

A Jarvis plugin (plugin spec 0.3). The contract is `spec/plugin-spec.md` in the Jarvis repo.

- `plugin-kit.js` is a copy of the Jarvis plugin kit; do not edit it.
- `npm test` here runs this plugin on its own.
- In the Jarvis repo: `npm run dev` shows the card, `npm run plugin:check <this folder>` checks it.
